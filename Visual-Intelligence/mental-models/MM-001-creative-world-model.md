# Creative World Model

## Purpose

The Creative World Model (CWM) is the platform's internal representation of the creative universe for a specific project.

It transforms structured knowledge into a coherent mental scene before any reasoning or generation begins.

The CWM is not a prompt, an image, or a storyboard. It is an internal cognitive model that allows the platform to reason about creative decisions in context.

---

# Definition

A Creative World Model is a dynamic graph that captures:

- Project goals
- Brand context
- Characters
- Products
- Environments
- Narrative
- Emotional tone
- Visual language
- Constraints

Together, these elements define the "world" in which creative reasoning takes place.

---

# Responsibilities

The CWM MUST:

- unify information from all intelligence domains
- maintain project context
- provide a shared mental representation
- evolve as new information is discovered
- support reasoning across multiple scenes

The CWM MUST NOT:

- generate prompts
- render assets
- replace persistent memory
- override Visual DNA

# Shared Context

Every reasoning module reads from the same Creative World Model.

This ensures that all creative decisions are made using a consistent understanding of the project.

---

# Success Criteria

The CWM succeeds when:

- all reasoning modules operate on shared context
- conflicting assumptions are minimized
- project consistency improves over time
- creative decisions become explainable

---

# Engineering Notes

The CWM is a conceptual model.

Implementation may use:

- graph databases
- object graphs
- symbolic world states
- hybrid knowledge representations

The abstraction remains independent of implementation.
