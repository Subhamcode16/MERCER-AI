# Overview
This file captures the design tokens and rationale for Frame 01 of the Creative Intelligence Institute.

# Colors
The primary color is `Warm Ivory` (`#E1D4C0`). We avoid pure white to maintain a luxury, architectural feel.

# Typography
We use an Editorial Serif (Playfair Display) for the main headline, and a clean Sans-Serif (Inter) for secondary text. 

# Layout
Everything is absolutely positioned to let the environment be the protagonist.
- Margins: 8vw from left/right, 6vh from top.
- Empty space: Content occupies roughly 40% of the horizontal space, leaving 60% for the architecture.

# Do's and Don'ts
- **Do** prioritize Silence, Space, Architecture, Material, Light, and Calmness.
- **Don't** use floating UI cards, glassmorphism, bright gradients, large shadows, neon colors, or over-animated interfaces.
