# Phase 28: Skill Optimization & Worker Learning Contracts

## 1. Skill Optimization Contracts
Campaign critique failures generate `SkillImprovementProposal` records containing concrete training examples and prompt compiler adjustments. Skill proposals cannot modify security policies, RBAC gates, or authority parameters.

## 2. Worker Learning Invariant

$$\mathbf{Learning \neq Authority}$$

Performance tracking measures worker specialization affinity (e.g. tailoring, motion capture, jewelry rendering) to optimize work dispatch routing. High worker performance **never** expands authorization privileges or elevates worker roles.
