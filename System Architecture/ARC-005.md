## 1. Two-Phase Commit Credit Ledger Implementation
To prevent billing race conditions, the FastAPI backend uses atomic transactions across two collections: `users` (balance cache) and `credit_transactions` (immutable log).

### 1.1 Step-by-Step Operations
1. **Reserve Stage (FastAPI Router):**
   ```python
   # Atomic deduction check
   result = db.users.find_one_and_update(
       {"_id": user_id, "credit_balance": {"$gte": required_credits}},
       {"$inc": {"credit_balance": -required_credits}}
   )
   if not result:
       raise HTTPException(status_code=402, detail="Insufficient credits")
   
   # Write reserve ledger transaction
   db.credit_transactions.insert_one({
       "user_id": user_id,
       "job_id": job_id,
       "amount": required_credits,
       "type": "reserve",
       "timestamp": datetime.utcnow()
   })
   ```
2. **Commit Stage (On Success):**
   ```python
   db.credit_transactions.insert_one({
       "user_id": user_id,
       "job_id": job_id,
       "amount": required_credits,
       "type": "commit",
       "timestamp": datetime.utcnow()
   })
   ```
3. **Refund Stage (On Provider Failure):**
   ```python
   db.users.update_one({"_id": user_id}, {"$inc": {"credit_balance": required_credits}})
   db.credit_transactions.insert_one({
       "user_id": user_id,
       "job_id": job_id,
       "amount": required_credits,
       "type": "refund",
       "timestamp": datetime.utcnow()
   })
   ```

## 3. Waterfall Fallback Controller (Image Generation)
When calling AI provider APIs, the system intercepts quota and server errors to trigger an alternate execution path.

### 3.1 Fallback Waterfall Logic
```python
import logging

# Set up logging for tracking waterfall events
api_logger = logging.getLogger("api_waterfall")

async def generate_with_waterfall(prompt: str, user_tier: str):
    models = ["gemini-3.1-flash-image", "gemini-2.0-flash", "gemini-1.5-flash"]
    
    for model in models:
        try:
            api_logger.info(f"Attempting generation with model: {model}")
            result = await call_provider_api(model, prompt)
            return result
        except Exception as e:
            # Capture 429, 503, or 404 errors
            api_logger.warning(f"Model {model} failed: {str(e)}. Fallback triggered.")
            continue
            
    # If all models fail, raise custom exception to trigger credit refund
    raise GenerationEngineFailure("All models in waterfall returned errors.")
```
- **Error Logging:** All failures and fallbacks are logged to `.env`-configured log files (`planner_debug.log`) to assist developers during production debugging.
- **Safety Nets:** Wrapping the outer loop in try-except blocks ensures that failure refunds are guaranteed.
