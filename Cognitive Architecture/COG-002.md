## 1. End-to-End Pipeline Execution Flow
Every campaign creation request flows through a series of structured processing stages.

```
[User Ingress Request]
          │
          ▼
┌─────────────────────────────────┐
│  Stage 1: Validation & Auth     │ (Checks JWT & Credit Balance)
└─────────┬───────────────────────┘
          │ (Pass)
          ▼
┌─────────────────────────────────┐
│  Stage 2: Extraction & Routing  │ (Parses image & triggers domain plugin)
└─────────┬───────────────────────┘
          │ (Parsed)
          ▼
┌─────────────────────────────────┐
│  Stage 3: Prior Memory Search   │ (Retrieves brand memory & historic performance)
└─────────┬───────────────────────┘
          │ (Context loaded)
          ▼
┌─────────────────────────────────┐
│  Stage 4: Strategy Synthesis    │ (Creates Strategy Bento Cards)
└─────────┬───────────────────────┘
          │ (Render Strategy Grid)
          ▼
┌─────────────────────────────────┐
│  Stage 5: Collaborative Pause   │ (User edits & gives Green Signal)
└─────────┬───────────────────────┘
          │ (Approved)
          ▼
┌─────────────────────────────────┐
│  Stage 6: Safety & Credit Lock  │ (Runs moderation & atomic credit reserve)
└─────────┬───────────────────────┘
          │ (Locked)
          ▼
┌─────────────────────────────────┐
│  Stage 7: Execution & Fallback  │ (Submit model render / waterfall fallback)
└─────────┬───────────────────────┘
          │ (Delivered)
          ▼
┌─────────────────────────────────┐
│  Stage 8: Memory Commit         │ (Embeds decisions to Memory Graph)
└─────────────────────────────────┘
```

## 2. Detailed Stage Specifications

### Stage 1: Validation & Ingress Gate
- **Checks:** Validates JWT against Supabase Auth. Fetches `user.credit_balance` from MongoDB.
- **Rule:** Rejects request with `402 Payment Required` if balance is below cost target.

### Stage 2: Product Extraction & Domain Routing
- **Checks:** Passes uploaded image to Universal Product Engine. Parses silhouette, colors, and textures.
- **Rule:** Routes to `Human Expression` or `Living Environment` domain ruleset handler.

### Stage 3: Prior Memory Search
- **Checks:** Executes pgvector search matching `brand_id` and theme vectors.
- **Rule:** Loads previous successful visual directions and user preferred compositions.

### Stage 4: Strategy Synthesis
- **Checks:** Invokes the Planning Engine to compose target proposals.
- **Rule:** Outputs the Bento Strategy Cards dataset to the client browser.

### Stage 5: Collaborative Pause
- **Checks:** The workspace enters WebSocket sync. Awaits user overrides.
- **Rule:** The pipeline blocks further execution until client sends `green_signal: true`.

### Stage 6: Safety & Credit Lock
- **Checks:** Executes OpenAI/Gemini safety moderation on compile prompts.
- **Rule:** Atomically deducts credits (`reserve` entry in ledger).

### Stage 7: Execution & Fallback
- **Checks:** Passes compiled Creative State JSON to the Rendering Engine.
- **Rule:** Activates waterfall cascade if primary model returns 429 or 503 errors.

### Stage 8: Memory Commit
- **Checks:** Confirms generation success. Writes `commit` to ledger.
- **Rule:** Vectorizes final parameters and saves to the Memory Graph.
