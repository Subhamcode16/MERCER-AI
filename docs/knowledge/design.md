# Atelier OS
## Visual Design System

Version: 1.0
Status: LOCKED

---

# Philosophy

Atelier is not a dashboard.

It is a creative institution translated into software.

The interface should disappear behind the experience.

Every visual decision should reinforce calmness, confidence and craftsmanship.

The workspace should feel architectural rather than digital.

---

Always

✓ Architectural

✓ Material First

✓ Calm

Never

✗ SaaS

# Visual Language

The interface is inspired by:

- Contemporary Architecture
- Editorial Design
- Museum Spaces
- Luxury Fashion Studios
- Japanese Minimalism
- Apple's Human Interface Design

The application should feel closer to an architecture magazine than an AI application.

---

# Layout Philosophy

Every screen follows one principle.

One Hero.

Everything else supports it.

The user should never wonder where to look.

Visual hierarchy must remain obvious.

Whitespace creates structure.

Not borders.

---

# Spatial Language

Every page is divided into three architectural zones.

Navigation

↓

Workspace

↓

Supporting Intelligence

The workspace always dominates.

The interface never competes with the creative work.

---

# Workspace

The workspace is the heart of Atelier.

Everything revolves around it.

Examples

Material

Campaign

Moodboard

Image

Canvas

Creative Direction

The workspace should always occupy approximately sixty percent of the available width.

---

# Navigation

Navigation feels architectural.

Typography first.

Icons second.

Minimal.

Quiet.

No floating navigation.

No exaggerated sidebars.

Navigation remains permanently available without demanding attention.

---

# Typography

Typography communicates confidence.

Never excitement.

Hierarchy

Display

↓

Heading

↓

Section

↓

Body

↓

Caption

Generous spacing.

Comfortable reading rhythm.

Never condensed.

Never decorative.

---

# Color Philosophy

The interface uses restraint.

Background

Warm charcoal

Deep architectural black

Concrete grey

Primary Text

Soft white

Secondary Text

Muted warm grey

Accent

Golden afternoon light

Interactive

Apple Liquid Glass

Danger

Muted brick red

Success

Muted forest green

Never use saturated colors.

---

# Material Language

The interface is built from materials.

Not components.

Primary Materials

Concrete

Glass

Light

Paper

Linen

Every surface should communicate physicality.

---

# Surface Hierarchy

Primary Surface

Workspace

Secondary Surface

Editorial Panels

Tertiary Surface

Utility Panels

Glass

Interactive Elements Only

Never use glass as decoration.

---

# Apple Liquid Glass

Glass exists only where interaction occurs.

Examples

Buttons

Dropdowns

Inputs

Search

Floating Controls

Glass should never become the visual identity.

Architecture remains the identity.

---

# Border Philosophy

Avoid visible borders.

Separate information using

Whitespace

Alignment

Contrast

Typography

Light

Only use borders where absolutely necessary.

---

# Shadows

Very subtle.

Soft.

Diffuse.

No floating card shadows.

No exaggerated elevation.

Shadows exist only to reinforce depth.

---

# Corners

Large corner radii.

Inspired by Apple's Liquid Glass.

Every radius should feel soft and approachable.

Avoid sharp geometry.

---

# Buttons

Buttons feel like physical objects.

Primary Button

Apple Liquid Glass

Secondary Button

Text only

Tertiary Button

Minimal outline

Never use loud colors.

Never use heavy shadows.

---

# Inputs

Inputs should disappear into the architecture.

Minimal outlines.

Soft glass.

Large touch targets.

Comfortable spacing.

Typing should feel calm.

---

# Cards

Avoid traditional cards.

Instead use

Editorial Panels

Architectural Sections

Material Surfaces

Cards should never feel like widgets.

---

# Images

Images dominate.

Never thumbnails.

The uploaded material is always the hero.

Images should breathe.

Never squeeze content around them.

---

# Icons

Icons support typography.

Never replace typography.

Use simple line icons.

Consistent stroke.

Minimal detail.

---

# Spacing

Large spacing.

Comfortable rhythm.

Every screen should breathe.

Crowded interfaces are forbidden.

---

# Motion Philosophy

Motion exists to reinforce understanding.

Never delight for the sake of delight.

Every animation must answer

What changed?

Why?

Motion should feel inevitable.

---

# Animation

Slow.

Elegant.

Purposeful.

Examples

Fade

Opacity

Scale

Blur

Parallax

Never

Bounce

Elastic

Spin

Flash

Overshoot

---

# Hover

Hover should feel physical.

Slight lift.

Glass becomes clearer.

Border slightly brighter.

Nothing dramatic.

---

# Scroll

Scrolling feels cinematic.

Sections transition naturally.

No snapping.

No abrupt reveals.

The user should feel like walking through a building.

---

# Loading

Loading communicates thinking.

Never waiting.

The interface should always reveal Atelier's reasoning.

The user always knows what is happening.

---

# Empty States

Empty does not mean blank.

Every empty workspace should invite creation.

Examples

"Begin a New Campaign"

"Upload your first material"

Nothing more.

---

# Notifications

Minimal.

Passive.

Bottom corner.

Fade in.

Fade out.

Never interrupt creativity.

---

# AI Presence

Atelier is always present.

Never intrusive.

The AI observes quietly.

It appears only when valuable.

It should feel like an experienced creative director sitting beside the user.

---

# Accessibility

Readable typography.

Comfortable spacing.

Large interaction targets.

Keyboard accessible.

High contrast.

Motion reduction supported.

No interaction should rely solely on color.

---

# Performance

Every interaction should feel immediate.

Target

60 FPS

Fast transitions.

Minimal layout shifts.

Optimized image loading.

Lazy rendering where appropriate.

---

# Responsive Behaviour

The hierarchy never changes.

Only the layout adapts.

The workspace always remains the hero.

Navigation compresses gracefully.

Supporting panels reposition intelligently.

---

# Design Principles

Every screen should answer:

What is the user creating?

Everything else becomes secondary.

The interface should never compete with creativity.

---

# Success Criteria

If the Atelier logo is removed, users should still recognize the product by its visual language alone.

The experience should feel like entering the same architectural world introduced in World I.

The landing page and the application should feel like one continuous institution.

The user should never think,

"I opened an AI dashboard."

They should think,

**"I walked into Atelier."**
