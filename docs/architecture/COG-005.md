## 1. Specialized Agents & Core Responsibilities
The platform distributes cognitive tasks across specialized agent roles that read from and write to a shared Blackboard session.

```
                  ┌───────────────────────────────┐
                  │      Blackboard Session       │
                  │   (Active Campaign Canvas)   │
                  └──────────────┬────────────────┘
                                 │
         ┌──────────────┬────────┴───────┬──────────────┐
         ▼              ▼                ▼              ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│   Product    │ │   Campaign   │ │   Creative   │ │  Rendering   │
│   Expert     │ │   Planner    │ │ Review Engine│ │  Specialist  │
```

### 1.1 Product Expert Agent
- **Responsibility:** Extract, taxonomy-map, and verify physical product visual DNA.
- **Inputs:** Raw product image uploads.
- **Outputs:** Verified visual attributes schema (materials, textures, key parts).

### 1.2 Campaign Planner Agent
- **Responsibility:** Formulate strategic proposals and decompose campaign objectives into tasks.
- **Inputs:** User Business Intent, active Brand Guidelines, Memory Priors.
- **Outputs:** Proposed Campaign Strategy Bento Cards and task graph.

### 1.3 Creative Review Engine (CRE)
The CRE is the multi-objective evaluation engine of the platform. Rather than a single critic, it divides evaluations among five specialized sub-critic agents:
- **Brand Critic:** Verifies compliance with brand guidelines (color palette, logo safety, tone).
- **Product Critic:** Validates visual DNA representation and physical material constraints (e.g. flagging a drape that violates fabric weight physics).
- **Photography Critic:** Evaluates camera setups, focal lengths, angles, and lens behaviors against expert practices.
- **Marketing Critic:** Assesses target audience alignment, campaign semantics, and messaging.
- **Composition Critic:** Verifies layout rules, margins, bento card balances, and aspect ratio compliance.

*Outputs:* Evaluated constraints, compliance flags (`Pass`, `Soft Conflict`, `Hard Conflict`), and proposed relaxation trade-offs.

### 1.4 Rendering Specialist Agent
- **Responsibility:** Compile the final resolved Creative State into render prompts and coordinate waterfall API calls.
- **Inputs:** Resolved Creative State JSON from the Constraint Solver.
- **Outputs:** Final campaign visual assets.

## 2. Blackboard State Synchronization Protocol
Agents do not communicate via direct message passing. Instead, they interact asynchronously by writing to and reading from a shared, in-memory state repository called the **Blackboard**.

### 2.1 Protocol Rules
- **State Ownership:** Only one agent may hold write authority over a specific Blackboard key at any time.
- **Trigger Events:** Writing to a key publishes a state-update event, notifying subscribing agents.
- **Read-Only Access:** Subscribing agents can inspect any Blackboard key to inform their reasoning.

## 3. Shared Blackboard State Schema (`ActiveCampaignState`)
The blackboard maintains the session state during campaign development:
```json
{
  "session_id": "string",
  "campaign_id": "ObjectId",
  "blackboard_data": {
    "product_visuals": {
      "value": "ProductVisualAttributes",
      "writer": "ProductExpertAgent"
    },
    "strategy_cards": {
      "value": ["StrategyCard"],
      "writer": "CampaignPlannerAgent"
    },
    "creative_review_evaluations": {
      "value": {
        "brand_critic": ["EvaluationFlag"],
        "product_critic": ["EvaluationFlag"],
        "photography_critic": ["EvaluationFlag"],
        "marketing_critic": ["EvaluationFlag"],
        "composition_critic": ["EvaluationFlag"]
      },
      "writer": "CreativeReviewEngine"
    },
    "solver_output": {
      "value": {
        "satisfied_constraints": ["string"],
        "relaxed_constraints": [{
          "constraint_id": "string",
          "relaxation_rationale": "string"
        }],
        "explanation": "string"
      },
      "writer": "ConstraintSolver"
    },
    "compiled_creative_state": {
      "value": "CreativeStatePayload",
      "writer": "RenderingSpecialistAgent"
    }
  },
  "updated_at": "datetime"
}
```
If `creative_review_evaluations` contains any `Hard Conflict` flags from any sub-critic, the Rendering Specialist is blocked from compiling the Creative State until resolved by the Constraint Solver or approved by the user (Tier 3).
