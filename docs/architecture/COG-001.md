## 1. The Core Thinking Loop (ORRA)
The Creative Intelligence Platform reasons, adapts, and operates through a perpetual four-stage loop: **Observe, Reason, Remember, and Act**.

```
       ┌────────────────────────┐
       │       OBSERVE          │ ◄──────────┐
       │ (Ingest product/brand) │            │
       └───────────┬────────────┘            │

```

## 2. Loop Phases & Law Alignment

### 2.1 Observe (LAW-001 — Knowledge)
- **Input:** Raw visual uploads, text descriptions, brand parameters.
- **Process:** The system extracts raw visual data, applies domain taxonomies, and cross-references metadata.
- **Output:** Verified Product and Brand Knowledge claims.
- **Constraint:** The loop halts immediately if visual confidence falls below the 85% threshold, prompting human verification.

### 2.2 Reason (LAW-002 — Reasoning & LAW-004 — Collaboration)
- **Input:** Verified knowledge, user-provided Campaign Objectives, and target constraints.
- **Process:** Resolves optimal composition, lighting, environment, and styling layout.
- **Output:** The **Creative State** (a rendering-ready schema).
- **Constraint:** The Reasoning phase must display AI Strategy Cards to the user and await explicit approval (`Green Signal`) before transitioning to Action.

### 2.3 Act (LAW-005 — Autonomy)
- **Input:** Approved Creative State payload.
- **Process:** Resolves model parameters, executes prompt compilation, and submits jobs to the rendering engine.
- **Output:** Final Campaign Assets uploaded to Cloudflare R2 storage.
- **Constraint:** Operation requires credit reservation check and runs safety moderation gates before execution.

### 2.4 Remember (LAW-003 — Memory)
- **Input:** User overrides, final asset selection, and campaign click-through rates.
- **Process:** Generates dense vector embeddings of campaign choices and performs reinforcement/decay updates.
- **Output:** Updated Brand, Product, and Domain Memory graphs.
- **Constraint:** Memory acts as a contextual influence on the next iteration of the *Observe* and *Reason* phases, ensuring the loop compounds intelligence.

---

## 3. Loop Execution Integrity & State Transitions
- **No Phase-Bypassing:** Act cannot execute without a compiled Creative State from Reason. Reason cannot execute without validated attributes from Observe.
- **Error Remediation Loop:** If Act fails (e.g., API timeout), the pipeline triggers a roll-back operation, returns reserved credits, logs the exception details, and resets the loop back to the *Reason* state for alternative planning.
