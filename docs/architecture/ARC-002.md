## 1. FastAPI Endpoints Layout
The campaign reasoning and generation steps are exposed via a structured HTTP API.

### 1.1 Endpoint Catalog
- **`POST /campaigns`**
  - *Description:* Initiates a campaign container.
  - *Payload:* `{"brand_id": "string", "product_ids": ["string"], "objective": "string"}`
- **`GET /campaigns/{id}/strategy`**
  - *Description:* Generates 2-3 AI strategic proposals.
  - *Response:* `{"proposals": [{"theme": "string", "cards": ["StrategyCard"]}]}`
- **`PUT /campaigns/{id}/strategy`**
  - *Description:* Commits user overrides to Strategy Cards.
  - *Payload:* `{"theme": "string", "updated_cards": [{"card_id": "string", "value": "any"}]}`
- **`POST /campaigns/{id}/compile`**
  - *Description:* Transforms approved strategy cards into rendering-ready Creative State.

## 2. Domain Router Middleware
The backend uses a router pattern to dynamically load domain ontologies.

```
Incoming Request (Product & Campaign Details)
                  │
                  ▼
   ┌─────────────────────────────┐
   │    FastAPI API Endpoint     │
   └──────────────┬──────────────┘
                  │
                  ▼
   ┌─────────────────────────────┐
   │   Domain Router Middleware  │
   └──────────────┬──────────────┘
                  │ (Reads product.domain)
         ┌────────┴────────┐
         ▼                 ▼
 ┌──────────────┐   ┌──────────────┐
 │ Wearables    │   │ Living       │
 │ Controller   │   │ Controller   │
 └──────────────┘   └──────────────┘
```

### 2.1 Middleware Implementation Logic
1. Reads `product.domain` from the database.
2. Intercepts the request and loads the matching domain ruleset handler.
3. Inject the domain-specific solver guidelines into the Prompt Compiler.

## 3. Prompt Compiler JSON Schema
The compiler resolves Strategy Cards into the standardized **Creative State** JSON payload, decoupling reasoning from the final image generation model.

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "CreativeStatePayload",
  "type": "OBJECT",
  "properties": {
    "composition": {
      "type": "OBJECT",
      "properties": {
        "layout_rule": { "type": "STRING" },
        "focal_point": { "type": "STRING" }
      },
      "required": ["layout_rule", "focal_point"]
    },
    "lighting": {
      "type": "OBJECT",
      "properties": {
        "style": { "type": "STRING" },
        "contrast": { "type": "STRING" },
        "color_temperature": { "type": "STRING" }
      },
      "required": ["style", "contrast", "color_temperature"]
    },
    "material_preservation": {
      "type": "OBJECT",
      "properties": {
        "weave_details": { "type": "STRING" },
        "reflectance_level": { "type": "NUMBER" }
      }
    },
    "environment": {
      "type": "OBJECT",
      "properties": {
        "background_description": { "type": "STRING" },
        "surface_type": { "type": "STRING" }
      },
      "required": ["background_description", "surface_type"]
    }
  },
  "required": ["composition", "lighting", "environment"]
}
```
