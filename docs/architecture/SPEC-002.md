## 1. Campaign Strategy Formulation
The platform must transform raw user intent (business objectives) into a structured campaign strategy.

### 1.1 Strategic Input Schema
- **Target Audience:** Demographic and psychographic segments (e.g., "Minimalist luxury buyers", "Gen Z streetwear advocates").
- **Core Value Proposition:** Product benefits emphasized (e.g., "Handcrafted weave", "Full-grain durability").
- **Marketing Channels:** Intended platforms (e.g., Shopify storefront, Meta ads, Instagram, Pinterest).
- **Target Campaign Timeline:** Seasonal, promotional, or evergreen.

### 1.2 Strategic Deliverable Output
- The platform outputs a **Campaign Strategy Summary** comprising:
  - An overarching **Narrative Theme**.
  - A structured set of **Channel Specific Deliverables**.
  - High-level **Success Metrics** matching the business goals.

## 2. Creative Direction Rules
Creative direction translates campaign strategy into visual guidelines.

### 2.1 Aesthetic Mapping
- The platform maps the campaign strategy to visual styles using the **Brand Profile** constraints:
  - **Tone of Voice Mapping:** Translates textual brand identity to visual parameters (e.g., "Professional Voice" maps to high-key lighting, balanced compositions).
  - **Moodboard Generation:** Generates a 4-quadrant conceptual moodboard specifying color palettes, style vectors, and visual context.

---

## 3. The Creative State Specification
The reasoning process must compile a complete, rendering-ready definition called the **Creative State**. 

### 3.1 Creative State Schema Attributes
- **Camera:** Focal length (e.g., "85mm close-up"), angle (e.g., "Eye-level", "Low-angle dynamic"), and focus depth.
- **Lighting:** Setup type (e.g., "Chiaroscuro", "Diffused soft studio", "Golden hour side-light") and light source positions.
- **Environment:** Background description, physical setting parameters, surface materials (e.g., "Polished marble floor", "Natural linen drop").
- **Composition:** Structural layout (e.g., "Rule of thirds centered", "Asymmetrical left-weighted").
- **Styling Details:** Prop coordination, model pose parameters, and secondary visual assets.

---

## 4. Alternative Justification UI
For major decisions, the platform must display alternative options.

### 4.1 UI Design Guidelines
- **Alternative Selection Bento Grid:** Displays 2 to 3 alternative creative directions.
- **Justification Cards:** Each option must contain:
  - **Strategic Value:** Explanation of *why* this direction is proposed.
  - **Confidence Rating:** Numeric value indicating reasoning viability.
  - **Aesthetic Direction:** Miniature moodboard preview representing the execution pathway.
