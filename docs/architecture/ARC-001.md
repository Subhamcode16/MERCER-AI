## 2. Universal Product Engine Specifications
The Product Engine runs vision analysis using base foundation model extraction.

### 2.1 Attribute Parser Schema
The engine outputs a unified metadata JSON that populates the product document:
```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "ProductVisualAttributes",
  "type": "OBJECT",
  "properties": {
    "silhouette_extracted": { "type": "BOOLEAN" },
    "detected_materials": {
      "type": "ARRAY",
      "items": {
        "type": "OBJECT",
        "properties": {
          "type": { "type": "STRING" },
          "reflectance": { "type": "NUMBER" },
          "texture_pattern": { "type": "STRING" }
        }
      }
    },
    "color_palette": {
      "type": "ARRAY",
      "items": { "type": "STRING" }
    }
  },
  "required": ["silhouette_extracted", "detected_materials", "color_palette"]
}
```

## 3. Ontology Graph Relations (Knowledge Graph)
The platform models relationships semantically to enable contextual queries.

### 3.1 Edge Types & Rules
- **`OWNED_BY`:** (Product $\rightarrow$ Brand). Schema restriction: exactly 1 outgoing edge.
- **`MEMBER_OF`:** (Product $\rightarrow$ Domain). Schema restriction: exactly 1 outgoing edge.
- **`PROMOTED_IN`:** (Product $\rightarrow$ Campaign). Schema restriction: many-to-many.
- **`AESTHETIC_ALIGNED`:** (Campaign $\rightarrow$ Brand). Validates color space and typography constraints.
